# Лабораторная работа №6
Моделирование временных рядов с помощью ARIMA, SARIMA и SARIMAX

📌 Описание проекта

В рамках работы выполнен анализ временного ряда объема розничных продаж на основе данных интернет-магазина (период с 2010 по 2011 год). Исходные данные представляют собой детализированный лог транзакций с информацией о товарах, количестве покупок, ценах и географии продаж.

В ходе подготовки данных был сформирован агрегированный временной ряд (ежедневный/еженедельный объем продаж), что позволило исследовать динамику покупательской активности.
Основные задачи:
    Исследование структуры ряда (тренд, сезонность, стационарность),
    Построение базовой модели ARIMA с ручным подбором параметров,
    Диагностика остатков и улучшение модели,
    Внедрение сезонной компоненты (SARIMA).
